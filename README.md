# Лабораторні роботи з дисципліни "Алгоритми та структури даних"

## Виконала: Газдун Христина Романівна (ІР-13)

### Лабораторна рото №7 (Варіант 2)

Суть задачі полягає в тому, щоб збудувати максимально економну, але цілісну мережу зв’язку. У нас є набір телекомунікаційних колодязів, які потрібно з'єднати оптоволокном так, щоб кожен колодязь був підключений до загальної мережі, але при цьому загальна довжина витраченого кабелю була найменшою з усіх можливих варіантів.

Ми будуємо мінімальне кістякове дерево на графі. Ми розглядаємо кожен колодязь як вузол, а можливі шляхи між ними — як лінії з певною вагою (відстанню). За допомогою алгоритму ми відкидаємо всі зайві та занадто дорогі маршрути, залишаючи лише ті, що створюють єдину мережу без замкнених циклів. Якщо ж виявляється, що якісь колодязі фізично неможливо з'єднати з іншими, програма сигналізує про це результатом -1.
