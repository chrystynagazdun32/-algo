# Лабораторні роботи з дисципліни "Алгоритми та структури даних"

## Виконала: Газдун Христина Романівна (ІР-13)

### Лабораторна рото №5 (Варіант 2, рівень 3)

Я реалізувала алгоритм для пошуку найкоротшого шляху шахового коня на дошці заданого розміру. Для вирішення завдання я обрала пошук у ширину (BFS), оскільки цей алгоритм ідеально підходить для графів з однаковою вагою ребер і гарантує знаходження мінімальної кількості кроків. Програма зчитує дані з файлу input.txt, при цьому вона автоматично ігнорує коментарі після символу решітки та коректно обробляє координати, навіть якщо вони записані через кому. У процесі роботи алгоритм використовує чергу для перебору можливих ходів та множину відвіданих клітинок, щоб уникнути зациклення та зайвих обчислень. На кожному кроці скрипт перевіряє вісім стандартних напрямків руху коня, контролюючи, щоб нова позиція не виходила за межі шахівниці. Результат розрахунку у вигляді одного цілого числа записується у файл output.txt, що забезпечує швидку перевірку правильності роботи коду. Алгоритм має оптимальну складність $O(N^2)$, що дозволяє миттєво знаходити шлях навіть на великих полях.
